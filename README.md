# 🏠 House Price Prediction Using Machine Learning

## 📌 About the Project

This project focuses on predicting house prices using machine learning techniques and Python. It aims to explore how property features can help estimate house prices.

## 🎯 Objectives

* Analyze real estate data.
* Clean and preprocess the dataset.
* Explore important property features.
* Train a machine learning model to predict house prices.
* Evaluate the model's performance.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## 📊 Features

* Real estate dataset analysis.
* Data cleaning and preprocessing.
* Machine learning model training.
* House price prediction.
* Model performance evaluation.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sujal99-dev/house-price-prediction-ml-model.git
```

### 2. Install Dependencies

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

### 3. Run the Python File

```bash
python project1.py
```
